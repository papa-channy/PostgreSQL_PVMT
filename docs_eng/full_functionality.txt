## Execution Flow (run_db.sh)

1. error_checklist.sh
   → Checks Docker daemon, ext4 mount, port conflicts, disk usage

2. compare_con.sh
   → Compares SSD containers vs local; asks for backup targets

3. Auto port management (9999↓) and log update

4. SSD latest container clone to db_vX+1

5. version_manage.sh
   → Detects schema diff (6543 vs 6544), saves diff, updates version.json

6. port_log.sh
   → Current port mappings saved to Desktop

---

## Error Recovery Logic

- Duplicate container name: skipped or renamed
- Port conflict: reassignment starts from 9999 down
- Dead container on core ports (6543~6545): interactive reassignment
- Docker or mount failure: all fail early before side effects
- Disk usage > 95%: warns and logs, but allows execution

## Data Tracking Files

- version.json — official version name registry
- all_change.sql — full change trace
- diff_vX.sql — single schema diff
- classified_diff.sql — labeled diff output
- backup_log.txt — backup activity timestamped
