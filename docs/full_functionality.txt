# PostgreSQL_PVMT: 전체 기능 설명서 (한글판)
작성일: 2025-04-30 17:53

이 문서는 PostgreSQL Portable Version Management Toolkit의 전체 구성과 기능을 설명합니다.

---

## 디렉토리 구조 (기본 설정 기준)

mydb/
├── db/                    # 각 컨테이너 버전별 볼륨 데이터
├── docker/                # (옵션) 도커 이미지 백업 영역
├── dl_fx/                 # 추후 딥러닝 함수 적용용 폴더
├── logs/
│   ├── backup_log.txt     # SSD → 로컬 복사 로그
│   ├── error.log          # 오류 메시지 기록
│   ├── version.json       # 버전 및 메타 정보 저장
│   ├── all_change.sql     # 전체 스키마 변경 내역 누적
│   ├── diff_v*.sql        # 각 버전 간 차이 (최대 5개)
│   └── classified_diff.sql # 구조별로 분류된 변경 사항
├── scripts/
│   ├── run_db.sh          # 전체 실행 제어 스크립트
│   ├── compare_con.sh     # SSD vs 로컬 비교 및 복사
│   ├── version_manage.sh  # 스키마 차이 감지 + 버전 저장
│   ├── port_log.sh        # 현재 포트 상태를 바탕화면에 저장
│   ├── error_checklist.sh # 실행 전 전체 상태 점검
│   ├── req_set.sh         # 최초 환경 세팅용 스크립트
│   └── fstab_auto.sh      # UUID 기반 자동 마운트 설정

---

## 전체 실행 흐름 (run_db.sh 기준)

1. error_checklist.sh  
   → Docker, ext4, 포트 충돌, 저장공간 등 점검

2. compare_con.sh  
   → SSD 컨테이너 vs 로컬 비교 → 백업할 항목 선택

3. 포트 자동 배정 (9999부터 ↓) 및 로그 저장

4. SSD 최신 컨테이너 복제 → db_vX+1 생성

5. version_manage.sh  
   → 스키마 차이 감지 → diff 저장 → version.json 업데이트

6. port_log.sh  
   → 현재 포트 상태를 바탕화면에 저장

---

## 오류 복구 및 방어 전략

- 컨테이너 이름 중복: 자동 무시 또는 리네임  
- 포트 충돌: 사용 가능한 포트로 재배정 (9999 ↓)  
- 6543~6545 포트에 죽은 컨테이너: 자동 감지 + 대화식 재배정  
- Docker 또는 마운트 실패: 조기 종료 처리  
- 저장공간 사용률 95% 이상: 경고 후 진행

---

## 기록 및 추적 파일

- version.json — 버전 및 이름 매핑 정보  
- all_change.sql — 전체 변경 내역 누적  
- diff_vX.sql — 특정 버전 간 스키마 차이  
- classified_diff.sql — 항목별로 분류된 변경 내역  
- backup_log.txt — SSD → 로컬 복사 로그

---

## 확장 가능 기능

- 조용한 실행 모드: `run_db.sh --quiet`  
- alias 등록 가능: `rundb`, `checkport` 등  
- HTML 기반 포트 시각화 기능 추가 가능
